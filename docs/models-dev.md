# models.dev 推理能力缓存

模块使用 models.dev 的公开 v1 数据 `https://models.dev/api.json` 补充推理设置能力。远端更新已实现请求协议的模型 ID 和合法强度值，减少这类适配对 APK 更新的依赖。新的请求字段、认证方式或协议仍需代码适配；该功能不代表任意新模型或供应商都已验证可用。

没有新增设置页、开关或提示。原有推理强度控件继续使用同一套策略查询，缓存命中后可反映远端声明的合法选项；选择“模型默认”仍省略显式推理参数。远端目录不修改用户的 API 地址、模型 ID、协议或密钥。

## 获取与缓存

目录由模块进程在后台获取，不在推理请求路径同步等待网络。模块初始化与后续配置读取检查刷新期限，成功数据在 24 小时内复用；同一进程刷新失败后至少间隔 1 小时再尝试，退避计时不跨进程重启保存。支持 ETag 条件请求，HTTP 304 继续使用原有有效数据并更新时间。刷新失败、超时、超限或解析失败保留最近一次有效快照；首次尚无缓存时使用 APK 内置规则。

下载地址固定为 HTTPS 的 models.dev 公开目录。请求不携带用户模型端点、API 密钥、对话、提示词或屏幕内容，不接受远端提供的可执行代码或请求字段名。下载和目录条目数量均有限额，只有完成结构校验的快照才替换当前策略。

最近有效 JSON 与缓存元数据保存在模块私有的 `filesDir/models-dev/catalog.bin`，通过单个 `AtomicFile` 原子替换。其他应用及小爱宿主不直接读取该文件。网络失败不清空有效缓存，进程重启后可继续加载磁盘快照。磁盘载入同样异步执行，首次冷启动到有效快照发布之间的短窗口使用内置策略；目录发布后由后续配置读取取得新策略。

## 模型与协议匹配

先按配置 API 地址与完整模型 ID 匹配 provider；模型内的 `provider.api`、`provider.npm` 和 `provider.shape` 覆盖顶层声明。地址规范化只处理协议／主机大小写、默认端口、末尾斜杠和兼容的末尾 `/v1`，不跨域或按模型名称猜测供应商。同一地址和 ID 若声明冲突，保守保留“模型默认”，不合并成更宽的能力集合。

未知兼容网关可以使用受支持官方 provider 的完整模型 ID 回退。该回退限定为 OpenAI、DeepSeek 和 Alibaba/Qwen 的官方记录；支持相应明确命名空间，不把任意 provider 的同名模型合并。已知 provider 地址上的查找以该 provider 为准。远端未匹配时保留内置规则，不根据任意新模型名称前缀扩展能力。

`reasoning=true` 只表示模型具有推理能力，不能单独推出合法强度。`reasoning_options` 中的 `effort.values` 提供远端允许值；当前识别 `none`、`minimal`、`low`、`medium`、`high`、`xhigh` 和 `max`。空选项、未知值、未知请求形态及非文本模型不被推导为新的可调能力。

远端数据只选择本地已实现的请求方式：OpenAI 兼容 Chat Completions 的 `reasoning_effort`、Responses 的 `reasoning.effort`，以及已识别 Qwen 的 `enable_thinking` 和 DeepSeek 的 `thinking` 扩展。`toggle` 不会被统一翻译成所有供应商通用开关，`budget_tokens` 暂不支持。原生 Anthropic／Gemini 等请求形态仍不属于模块这两种协议的适配范围。采样参数清理及 token 字段转换随解析出的策略一起应用。

## 宿主快照与日志

配置 IPC 附带 `reasoningPolicy` 与 `reasoningPolicyIdentity`。身份由配置的 API 地址、模型 ID 和协议生成，宿主只接受身份匹配且本地可解码的策略；无有效快照时回退内置规则。`Config` 捕获不可变 `Plan`，运行中目录更新只影响后续配置读取和新请求，已有请求保留捕获的策略。同一请求不会因后台刷新而中途改写参数；独立任务继续保留任务开始时的配置。客户端缓存区分协议、档位和策略，客户端资源由既有热重载生命周期释放。宿主不自行下载目录，也不从远端接收模型凭据。

Android 日志 Tag 为 `MiAIPlusModelsDev`，记录缓存加载、远端刷新、目录规模、304 和失败回退等状态，便于排查目录是否生效。日志不输出下载正文、用户 API 密钥或对话内容。缓存更新本身不证明真实模型服务接受这些参数；mock、JVM 和设备验证结果分别记录在 `docs/validation.md` 及其分阶段记录中。
