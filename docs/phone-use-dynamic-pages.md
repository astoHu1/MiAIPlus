# 动态页面局部控屏实测

日期：2026-10-17。设备：Xiaomi 25019PNF3C / xuanyuan、API 37、小爱 8.2.65.4714（508002065）。本轮经用户授权操作真实应用，安装开发签名 Debug / AndroidTest；没有发送模型请求。

## 方法与范围

`RealPageGuardRunner` 通过真实 `ScreenService` 读取截图与无障碍树，按人工选定坐标反复调用 `PageGuard`，另外记录同一点的 `VisualRegion` 结果。每组以同一旧观察比较后续多帧，间隔 1.3–1.5 秒；不是每次重置基线后立即点击。通过指定动态位置的局部像素变化确认广告／视频／倒计时确实在变，不单凭包含系统时钟的整张截图变化判断。

实际导航使用 `NativeSession.handle` → 新观察复核 → `ScreenService.execute` → 主线程注入前复核，没有用 ADB 坐标点击替代工具执行。应用启动及退回登录／搜索入口的准备使用 ADB；需要关闭登录页时只关闭，不登录。没有发送消息、点赞、收藏、关注、发布、购买、领取或下载应用／资源包。

这是人工选择动作的真实应用执行器验证，未验证模型自主规划、宿主 ToolRegistry 路由、后台虚拟屏隔离或完整业务任务成功率。原始观察只留在忽略的 `work/real-page-guard/`，不纳入源码／发行包。

## 实测发现并修复的问题

1. 无文字但可点击的 `FrameLayout` 不是可靠的内容锚点：广告内部画面改变，容器边界和状态却不变。现在这类目标和空标签目标都需要局部像素证据。
2. 微博过渡期间无障碍子节点有时引用祖先，原深度优先读取重复输出根节点、TabHost 和导航，耗尽 250 节点预算。仅改广度优先仍在 20 次采样中误拒绝底部导航 3 次。按来源节点身份去重后，最终 20/20 放行；旁路读取 45 份观察，均保留一个首页节点，无重复导航。该轮树实际仅 7 个唯一节点，页面其余部分由截图观察，不能声称恢复了完整无障碍树。

广度优先保留并列区域的浅层控件，身份去重阻止循环；不同节点即使文字／边界相同也不会合并。新增单测覆盖大广告子树、祖先循环、外观相同的不同节点、新遮挡、转义与密码脱敏。

最终包已重新跑完六个应用的稳定入口采样与真实导航。232 项 JVM/Robolectric 测试通过；Debug、Release、AndroidTest 构建及两套完整 Lint 通过，0 errors（Debug 31 / Release 24 warnings）。探针已停止，设备回到测试前的桌面；无活动 instrumentation、无 DisplayHelper，`connected=true,busy=false`，无障碍服务列表和启用值与测试前逐字一致，reverse 未变化。小爱主进程 PID 与测试前一致，没有重启小爱。最终 Debug / AndroidTest 保留在设备上。

探针不写偏好，不改写 API 配置；安装会正常更新注入状态报告，未用配置整文件哈希宣称所有运行状态字段不变。本轮未发布安装包。

## 复现入口与限制

安装 Debug / AndroidTest 后可运行 `python3 scripts/device_test.py --real-page-guard`。准备连接后输出 `REAL_PAGE_READY`，探针等待人工命令，不自动选择应用或动作。模块私有 `files/real-page-guard/command.json` 接收 JSON；先写临时文件再重命名，避免读到半条命令。`response.json` 按 `id` 返回结果；`observation.json` 包含本次树和图像，只应写入本地忽略目录。

命令含 `id`、`op`、`package`。`observe` 固定比较基线；`sample` 另含归一化 `points`、`count`（最多 10）与 `delay_ms`；`begin`／`tap`／`end` 执行真实会话，`tap` 含 `point`、可选等待（最多 8 秒）；`stop` 结束探针。先看新观察，再人工选择允许的导航目标；目标或页面已变时必须重新观察，不自动重放旧动作。

两帧局部稳定不证明业务意图正确，也不能消除截图到注入之间的时间间隔。树仍有节点／字符预算；真正读不到的目标、覆盖节点或窗口变化继续拒绝。此处证据只覆盖列出的页面及动作，不是六个应用的全功能保证。
