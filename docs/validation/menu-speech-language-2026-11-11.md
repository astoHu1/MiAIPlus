# 菜单层次、语音回复与非简中控屏（2026-11-11）

本轮工作从干净的 `main`（`d3522b8`）开始，按用户提供的小米官方深浅色菜单参考调整设置弹窗，新增三档语音回复策略，并修复非简体中文系统下直接控屏请求落入旧执行链的问题。仅推送源码，不创建版本 tag 或正式 Release；本地优化 Preview 与正式分发包分别判断。

## 行为

- 设置下拉菜单使用原 Miuix 定位、圆角、展开／退出和返回手势，在实际菜单表面加柔和阴影、0.5 dp 细边框；深色表面略抬亮。控屏动作协议、其他设置下拉和日志菜单共用该实现。合成截图见 [设置界面](../settings-ui.md)。
- 首页「对话 → 语音回复」提供「仅文字／跟随输入／小爱默认」，默认跟随输入。真实识屏请求按文字处理，真正的麦克风输入仍属语音；按请求及 MiClaw 对话标识隔离，覆盖残留语音偏好、待机上下文与流式播放门。关闭覆盖保留宿主策略，且不改宿主持久化语音偏好。
- 非 `zh-CN` 系统下，启用自有前台 Phone Use 时，补充简体／繁体中文及英文直接控屏操作的 Agent 路由。普通技能、解释、拒绝控屏请求保持原路由，不全局伪造语言，也不放开小爱的旧 ActionNodes 执行器。详见 [语言行为与边界](../phone-use-language.md)。
- 精确宿主版本门禁、锁屏、安全窗口、密码／验证码、确认、取消、超时和前后台任务所有权不变。

## 设备与证据边界

使用已授权 Xiaomi 15 Ultra（API 37）、小爱 `8.3.30.4420` 与现有 root。配置、语言、夜间模式及无障碍列表在本地忽略目录备份；不提交个人配置、原始日志、凭证或设备界面。

优化 Preview 的菜单专项在浅色／深色分别打开控屏协议与三档语音菜单，核对选项边界、真实选择持久化以及返回；四张合成配置实机截图目视检查通过，原配置及夜间模式回读恢复。Robolectric 另覆盖 320 dp、1.5 倍字号和原页面亮度不变。第一次截图中途关闭物理显示导致深色图片复用了缓存帧，随后保持亮屏完整重跑，确认控屏与语音截图分别正确；不把缓存图当作视觉证据。

最终 Debug 语音专项三个策略逐轮通过：真实 coordinator 和 query builder 按「纯转写 → 语音 → 识屏 → 文字 → 语音交接 → 语音」提交，临时模拟宿主 `ttsMode=1`，检查真实请求参数、三类音频限制、最终 MiClaw 流式门禁与旧对话归属；非语音禁用项、环境字段和上下文头保留，纯转写继续走 `startAsr`。测试在底层 engine 原方法前停止，不录音、不播放音频、不调用模型；对话标识为合成测试标识，不能等同于人工听验全部播放路径。原偏好严格等值恢复。

真实系统语言分别切换至 `en-US` 和 `zh-TW`，由系统配置服务回读确认；宿主 Probe 直接读取宿主资源中的语言，不使用局部伪造 Context。在关闭全局模型覆盖、语音策略为小爱默认时，两种语言均通过：实际文字入口提交「打开计算器」「打開計算機」各一次，主语音请求接收合成最终识别文本后恰好交接一次，重复结果受抑制。Probe 在 Agent 提交边界停止，避免模型或用户历史副作用；这项证据不证明声学识别质量。

纯转写修订后，再以最终「跟随输入」策略、关闭全局模型覆盖，在 `en-US` 和 `zh-TW` 完整重复上述真实文字与主 ASR 入口，均通过；最后系统配置服务确认恢复 `zh-CN`。

另在 `en-US` 下使用用户已配置的真实外部模型完成前台计算器任务：从测试图片页观察，调用自有 `miaiplus_phone_use`，启动计算器并执行 12 次点击，结果 `3973` 经两次所属观察帧的像素核验，模型实际发出 `finish`，任务、辅助屏和原对话返回清理通过。逐步附图序列 14 次匹配、0 次不匹配。该项开启全局模型覆盖，与前述关闭覆盖时的入口测试分别判断；没有验证最终聊天回复正文、任意任务成功率、小米官方模型或后台控屏质量。

## 修订与未覆盖项

补充语音上下文检查曾发现宿主原生禁读 builder 只禁用 `LLM_TTS_AUDIO`。修订为文字模式明确禁用 TTS、流式 TTS 与 LLM 音频，合并原限制，保留非语音禁用项、环境字段及原上下文头。初版仅按旧上下文数量／单个 TTS 类型断言的失败轮不计通过。

真实非中文 ASR 入口还发现「跟随输入」不应把纯转写、无 NLP／回复的请求改成语音回复请求；修订保留纯转写原参数，后续真正交给 Agent 的语音请求独立保留语音来源。该失败及其修订与系统语言限制分开判断，不能通过放宽语音请求所有权来掩盖。

旧小爱 `8.2.65.4714` 的精确绑定经源码与符号表核对，本轮未降级实机验证；不同 ROM、其他自然语言自由表达、热词／实体手势声学识别和所有最终音频播放路径未逐项人工听验。
