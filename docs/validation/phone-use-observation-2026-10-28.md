## 观察质量边界

裁剪不等于语义无损：首节点单行超过预算时会整行省略，后续行也可能未展示；当前没有按需全文工具。模型须结合截图，内部安全证据仍完整。长页面在同一字符预算下可展示更多完整行，中文比例变化会使单帧 UTF-8 字节略增，不能宣称每帧请求或 token 都减少。

历史真实应用树离线对照、此次真实应用执行器验证、mock 协议检查与真实模型任务质量是不同证据。没有同模型成对 A/B、真实 usage 或任务成功率样本时，不宣称推理延迟、成本、长程记忆或模型完成率提升。
