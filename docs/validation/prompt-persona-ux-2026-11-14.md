# 系统提示词与人设交互修订（2026-11-14）

本轮修订系统提示词设置页，解决菜单选择仍需保存、方案操作难以理解及保存入口不清楚的问题。注入路径沿用[初版实现](prompt-persona-2026-11-14.md)。初版的草稿离开确认与底部保存栏已被本轮交互替代。

## 行为

- 生效方式和三个开关即时保存，不连带提交正在编辑的名称或正文。
- 「人设方案」打开二级菜单，列出已保存方案，并用蓝色区分「新建人设」操作。新建只填写名称，再编辑空白正文。
- 编辑区只保留「保存当前人设」和「删除当前人设」。保存覆盖当前方案；删除后切到剩余方案，最后一套不能删除。
- 切换使用目标方案已保存的正文；各方案未保存的编辑留在内存，切回可继续编辑。离开页面不弹保存确认，进程结束后恢复已保存内容。
- 移除「还原／保存配置」底栏、另存操作和重复解释文案。
