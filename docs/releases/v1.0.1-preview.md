# MiAIPlus v1.0.1-preview

本版修复 Phone Use 在系统弹窗和敏感操作确认时中断的问题，并增加三档权限预设。

## 主要变化

- **Manual / Auto / YOLO**：在「控屏 → 权限 → Phone Use 权限预设」选择。默认 Manual，敏感操作逐次确认；Auto 增加模型审计步骤，不确定时转人工；YOLO 自动同意普通敏感操作，严重风险仍需确认。新预设对新任务生效。
- **系统弹窗与会话连续性**：可读取小米安全中心普通页面、应用选择器及可读授权窗口，待选择状态保留原会话；启动请求不再被误报为已经打开目标应用。
- **灵动岛确认**：修复空进度吞掉确认卡及通知发布失败后不再重试的问题。前后台敏感操作使用相同的确认链路，批准后重新核对目标并继续原任务。
- **截图与后台隔离**：修正缩小 JPEG 后的坐标换算，并为连续截图增加可取消间隔。后台操作保持独立显示与主屏输入法隔离，失败不静默回退物理屏。
- **继承 main 的改进**：对话闲置管理、控屏步数和错误终态处理、虚拟屏画布配置、OpenCode 会话请求头及全局模型设置联动。

## 验证与范围

345 项 JVM／Robolectric 测试通过，Debug／Release Lint 均无错误，Debug、Release、Preview 和 AndroidTest 参与发布构建。

在 Xiaomi xuanyuan／API 37／小爱 8.3.30.4420 上通过确定性实机验收：31 阶段前后台权限确认、三档设置保存与重建、真实 Android chooser 同会话选择、动态页面重新规划、灵动岛连续性及后台输入隔离。权限审计回复为测试 fixture，没有调用真实模型；未知 ROM、语言及授权模板未全部覆盖。详细证据见 [验证记录](../validation.md)。

锁屏、安全窗口、密码、验证码／CAPTCHA、任务所有权、取消和超时限制始终生效。Auto 的审计不代表独立安全模型保证。

## 安装

使用本预发布附带的正式签名 `MiAIPlus-1.0.1-preview.apk`；源码包和 `SHA256SUMS.txt` 用于复核。保留 `v1.0.0-preview` 历史记录。

需要支持 API 102 的 LSPosed，以及小爱 8.2.65.4714 或 8.3.30.4420。升级后重启小爱或按模块热重载要求操作。本版旧小爱绑定保留，但实机未降级复测。
