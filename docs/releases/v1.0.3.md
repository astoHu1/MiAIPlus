- 接入 Eta。在插件页打开「Eta Agent」后，小爱可把多步骤、跨应用、深度研究等任务交给 Eta 完成并取回结果。需要已安装官方发布版 Eta 3.4.4 或更新版本，并在 Eta 里配置好模型。MiAIPlus 不修改 Eta。
- 新增 Eta 控屏协议。控屏页「动作协议」可选 Eta，控屏请求全部交给 Eta 规划和执行。
- 新增系统提示词页，可追加或替换小爱的系统提示词，并保存多套人设。默认关闭。
- 改进 Termux 命令执行：命令原样交给 Bash 运行，支持有时限的后台任务。
- 推理强度选项改为参考 models.dev 公开目录，新模型的合法强度值可随目录更新，减少对 APK 更新的依赖。
- 优化菜单样式、语音与语言路由、前台控屏上下文和诊断日志覆盖。

兼容 Android 13+、LSPosed API 102；支持小爱同学 8.2.65.4714 和 8.3.30.4420。
