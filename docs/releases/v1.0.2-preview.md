# MiAIPlus v1.0.2-preview

## 更新

- 「插件」成为底栏入口，统一管理前台控屏、后台控屏和 HTTP MCP 工具。
- MCP 支持添加服务、Token、获取工具、查看参数、启停和取消调用；可选择 `2025-11-25` 或 `2025-06-18` 协议。
- 精简设置页说明，操作确认改为「手动确认／智能判断／自动执行」。修正 MCP「添加」按钮的尺寸、对齐和卡片间距。
- 保留主线 Phone Use 观察整理、执行状态反馈与请求计量优化。
- 包含应用内日志查看与 ZIP 导出、全屏／浮窗对话闲置超时修复，以及设置页布局和切页动画改进。
- README 更新为当前界面路径，并补充 MCP 使用步骤。

## 安装

下载 `MiAIPlus-1.0.2-preview.apk`，在 LSPosed 启用模块后重启小爱。安装包沿用 `io.github.miaiplus`，无需改动原作用域。

需要支持 miclaw 的 HyperOS 3+、LSPosed API 102，以及超级小爱 8.2.65.4714 或 8.3.30.4420。后台控屏需要给 MiAIPlus 授予 root。

发布 APK 使用正式发布签名。之前安装的是本地开发签名 Preview 时，不能直接覆盖安装；请先保留自己的配置。
