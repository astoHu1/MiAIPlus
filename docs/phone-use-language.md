# 非简体中文下的 Phone Use

MiAIPlus 自有的前台／后台控屏不依赖小爱旧控屏执行器的系统语言检查。精确适配的小爱 8.2.65.4714 和 8.3.30.4420 中，原生 ActionNodes 执行器在非 `zh-CN` 环境会拒绝，MiClaw Agent 的提交入口本身没有该语言门禁。

系统语言不是 `zh-CN`，且模块目录提供已启用的自有前台 Phone Use 工具时，明确的直接屏幕操作请求通过文字提交和仍属于当前主语音请求的最终 ASR 结果进入原生 MiClaw Agent。补充覆盖简体／繁体中文和英文的直接打开、点击、滑动、输入等入口，避免这些请求落回有语言门禁的旧执行器；既有明确控屏及应用内操作规则继续生效。普通对话、天气／闹钟等技能、提问／操作说明及明确拒绝控屏保留原路由，不自动开始控屏。模块或前台控屏插件关闭时不启用此语言路由；配置 IPC 不可用时不能借用旧工具目录。其他语言的自由表达仍受现有意图匹配和模型能力限制，未宣称覆盖任意语言的所有说法。

模块不修改系统语言，不把宿主全局 `isZhCN` 伪装为真，也不放开旧 ActionNodes 执行器。宿主现有设备支持检查，以及模块锁屏、安全窗口、密码、验证码、确认、所有权、取消和超时仍有效。工具说明明确只有本模块控屏不受旧语言限制；这不表示其他原生技能支持所有语言。

本轮设备验证结果记录在 [验证摘要](validation.md)。源码边界和单元测试不能代替非中文系统语言下的真实文字／最终 ASR 入口验证；声学识别及各种语言的模型任务质量需要分别判断。
